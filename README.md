# Airbnb Market Analysis & Dashboard

## Overview

Analyzed Airbnb listings using Python and Power BI to uncover pricing patterns, host performance, room type trends, and customer preferences.

## Tech Stack

### Data Analysis
- Python
- Pandas
- NumPy

### Data Visualization
- Matplotlib
- Seaborn
- Power BI

### Development Environment
- Jupyter Notebook

### Data Preparation
- Microsoft Excel
